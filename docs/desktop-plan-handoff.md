# 从 Codex 桌面对话提交定稿计划

更新后重新启动工作台，并重新加载 Codex 的 MCP 工具连接。新增工具为 `create_planned_task`。

在桌面对话中可说：“按刚才定稿的计划，在跨应用协作系统创建任务，跳过规划，授权自动实施。”

Codex 先通过 `list_tasks` 获取项目 ID，再提交任务名称、需求与修改范围、验收标准、完整计划、唯一 requestId，以及 automation（enabled 或 disabled）。计划应包含执行步骤、允许修改的文件、检查方式和停止条件。

任务直接进入 ready 队列，计划版本为 1。enabled 授权该任务自动实施；全局自动协作仍需开启，执行端仍需配置并登录。全局关闭时任务留在队列，不自动开启全局调度。当前独立实施端若配置为 CodeBuddy Code，仍由其执行 WorkBuddy 角色。

断线后用相同 requestId 和相同参数重试会返回原任务；内容不同会报冲突。运行中仍遵守项目占用、租约、暂停、阻塞诊断和人工验收规则。不会将其他桌面对话自动抓取为任务，只有明确调用提交工具才创建。
